# Handoff notes

One file per long-lived role: `tech-lead.md`, `producer.md`, `mapgen.md`, `art-director.md`, `qa.md`.

A replacement agent reads its role's file first. See `docs/process/studio.md` §6 for what a good handoff contains. Keep the Status Digest (Producer) under one screen.

Commit handoffs via PR titled `chore(handoff): <role> <YYYY-MM-DD>`. The Tech Lead fast-tracks these.
